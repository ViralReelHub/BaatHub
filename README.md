# BaatHub - Real-Time Chatting Website

## Setup Instructions
1. Computer mein **Node.js** install karein.
2. Terminal/CMD mein is folder (`my-chat-website`) ke andar jayein.
3. Dependencies install karne ke liye command chalayein:
   ```bash
   npm install
   ```
4. Server start karein:
   ```bash
   npm start
   ```
5. Browser mein `http://localhost:3000` kholein.

## Deployment & Google Indexing
- Is folder ko apne **GitHub** account mein upload karein aur **Render.com** ya **Railway.app** par deploy karein.
- Live hone ke baad **Google Search Console** mein apna domain add karein aur `https://aapkadomain.in/sitemap.xml` submit karein.
- **Google AdSense** approve hone ke baad `public/index.html` ke `.ad-banner` div mein apna ad code paste karein.
